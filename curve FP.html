曲面指紋展平實驗室 Prototype 虛擬 L 貼紙尺 + X/Y/對角曲率 + 3D 姿態反算

1. 表面範圍

先讓半透明網格覆蓋要校正的指紋區。直接在左圖拖曳可移動整個模型。

2. 3D 拍攝姿態

這一層主要消除「斜拍」。可直接在左圖用中鍵拖曳旋轉：左右＝Yaw、上下＝Pitch；Shift + 中鍵＝Roll。滑桿保留作精細修正。

3. 貼紙 / 曲面彎曲

正負值代表凸 / 凹方向。這不是「拉紋線」，而是改變整張貼附表面的幾何。對角線彎曲可補足單純 X/Y 不夠時的斜向貼附變形。右側展平與匯出都直接從乾淨原圖取樣；格線、虛擬尺、控制點只存在於左側操作預覽。

4. 虛擬 L 比例尺

實際只有單邊比例尺時，也可先用其中一支對準；另一支當作曲面方向輔助，不視為真實量測資料。

操作

滑鼠在參考平面內時操作模型；滑鼠在參考平面外時，左鍵拖曳與滾輪改為移動／縮放底圖。右側展平結果使用原始影像像素重新取樣，可拖曳與縮放檢查細節。
